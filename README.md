## ⚡ Что делает система на полном автомате:

1. **Стабильная работа 24/7 с Real:** Встроенный HWID Spoofer и обход мьютекса в Real (`ROBLOX_singletonMutex`) снимают любые системные ограничения Windows и позволяют открывать 10–50+ окон без крашей и конфликтов.
2. **Полноценный Мульти-Инжект (Multi-Instance 10–50+ окон):** Real автоматически подхватывает каждый новый процесс `RobloxPlayerBeta.exe` и внедряет скрипт из папки `autoexec` за доли секунды.
3. **Изумрудный GUI Farm Manager с мониторингом:** Удобный винтажный графический интерфейс в едином стиле с твоим ПК — живые карточки активных окон, уровень, объективный трекинг мешка (`Bag: X/40`), суммарный баланс монет, потребление ОЗУ, кнопка паузы/включения и блок критических ошибок с логинами и паролями.
4. **Умный фильтр сбоев (>5 ошибок подряд):** Временные дисконнекты или кики (коды 277, 268) автоматически рестартят окно без засорения интерфейса. В блок ошибок и `errors.json` аккаунт попадает **только при более чем 5 сбоях подряд**.
5. **Безопасная скорость сбора (22 studs/s):** Персонаж фармит на проверенной безопасной скорости без триггеров серверного античита MM2 и без киков.
6. **Авто-выход и чистый перезапуск при дисконнекте:** Если окно получает ошибку (267, 273, 277, 279, 529), скрипт вызывает `game:Shutdown()` и сообщает менеджеру, который мгновенно убивает зависший процесс и запускает новое чистое окно.
7. **Аппаратная оптимизация ОЗУ (Extra RAM):** На старте автоматически отключаются тяжёлые текстуры, 3D-рендер и лишние эффекты, позволяя держать десятки окон на обычном ПК.
8. **Анти-столкновение ботов:** Боты никогда не фармят на одном сервере. Менеджер выделяет отдельные публичные сервера (2–8 игроков). При случайном столкновении боты взаимно блокируют друг друга через API и расходятся по разным серверам.
9. **Умный Шериф и Маньяк:** Если бот получает роль Шерифа — он не ждёт заполнения сумки монетами, а зависает на 12 студов выше маньяка и мгновенно расстреливает его из револьвера.
10. **Автоматический сбор монет и Noclip:** Сбор монет сквозь стены на максимальной безопасной скорости.
11. **Статистика в 1 строку:** В файле `mm2_farm_stats.txt` хранится строго **1 строка на каждый активный аккаунт** (`User: Nick | Level: Lvl | Bag: X/40`) без мусора и дубликатов.
12. **Авто-получение куки из BloxGen / Real:** Больше не нужно вручную логиниться через браузер и доставать куки через F12 (DevTools)! Кнопка **«⚡ АВТО-КУКИ ВСЕГО»** прямо в GUI или команда `py farm_manager.py --cookies` на чистом автомате авторизует пачку аккаунтов, получает `.ROBLOSECURITY`, определяет `userId` и сразу заносит в ферму.
13. **Авто-перенос в `done.txt` и FunPay (100 lvl + 40k монет):** При достижении **100 уровня** и накоплении от **40 000 монет** аккаунт автоматически закрывается, удаляется из активного пула и переносится в `done.txt` в строгом формате для FunPay:  
    `name: nick pass: password, 100 lvl, 40k+ coins`  
    Менеджер сам поддерживает вечный онлайн на FunPay, авто-поднимает лоты и обновляет наличие!

## 🚀 Пошаговая настройка с нуля (Разберётся даже ребёнок)

### Шаг 1. Установка Python (если ещё не установлен)
1. Скачай Python с официального сайта: [python.org/downloads](https://www.python.org/downloads/) (версия 3.10 или новее).
2. Запусти установщик.
3. **ГЛАВНОЕ:** На самом первом экране установки ОБЯЗАТЕЛЬНО поставь галочку внизу:  
   `[X] Add python.exe to PATH` (без этого батник не увидит питон!).
4. Нажми **Install Now**.

---

### Шаг 2. Настройка экзекутора Real (Рекомендуется для 10–50+ окон)

1. **Установка и запуск Real:**
   - Запусти `RealSetup.exe` (скачивается с официального сайта `projectreal.live` или из загрузок).
   - Активируй ключ на сутки (1 раз на весь ПК).
   - Запусти **Real** от имени администратора. Встроенный спуфер Real снимет ограничения Windows и снимет мьютекс `ROBLOX_singletonMutex`, позволяя открывать 10–50+ окон без взаимных закрытий.
2. **Настройка папки `autoexec` для Real:**
   - Нажми `Win + R`, введи:
     ```cmd
     %localappdata%\Real
     ```
     и нажми Enter (откроется папка `C:\Users\ТВОЙ_ЮЗЕР\AppData\Local\Real`).
   - Внутри этой папки открой папку **`autoexec`** (если такой папки ещё нет — создай её: *ПКМ -> Создать -> Папку -> `autoexec`*).
   - Внутри папки `autoexec` создай файл **`farm.lua`** (убедись, что расширение именно `.lua`, а не `.txt`).
   - Открой `farm.lua` через Блокнот и вставь туда **всего одну строчку**:
     ```lua
     loadstring(game:HttpGet("https://raw.githubusercontent.com/surf1k/ym1co-farmer/main/main.lua"))()
     ```
   - Сохрани файл (`Ctrl + S`) и закрой Блокнот.
   > *Что это даёт:* Теперь Real при появлении любого нового окна Roblox сам автоматически внедряет скрипт за доли секунды!

> *(Запасной вариант — Xeno):* Если для тестов запускаешь до 7 окон на Xeno — папка `autoexec` находится по пути `%localappdata%\Xeno\autoexec\farm.lua` (в настройках Xeno включи Auto-Execute).

### Шаг 3. Добавление аккаунтов в ферму (Автоматически или вручную)

#### Вариант А. На полном автомате (Рекомендуется для BloxGen / Real):
1. В GUI фермы нажми кнопку **«⚡ АВТО-КУКИ ВСЕГО»** (или выполни команду `py farm_manager.py --cookies`).
2. Нажми **«🔍 Поиск в Real»** (он сам найдёт сгенерированные BloxGen аккаунты в хранилище Real) **ИЛИ** просто вставь список логинов и паролей (например `Activexstorm5502:SYPYlrPj8xuRh` или через пробел).
3. Нажми **«⚡ АВТО-КУКИ ВСЕГО»**.
4. Скрипт через фоновый Playwright Chromium сам выполнит вход на roblox.com, получит защищённую куки `.ROBLOSECURITY`, определит числовой `userId` и сразу добавит готовые аккаунты в `accounts.txt` и `accounts_pool.txt`. Руками делать ничего не нужно!

#### Вариант Б. Вручную:
1. В папке с фермой открой файл **`accounts_pool.txt`** (или нажми **«➕ Добавить Аккаунт»** прямо в GUI).
2. Вставь свои аккаунты по одной строке в формате:
   ```text
   Логин:Пароль:Куки_.ROBLOSECURITY
   ```
   *Пример:*
   ```text
   Fmr_bot1:Password123!:_|WARNING:-DO-NOT-SHARE-THIS...
   Fmr_bot2:Password123!:_|WARNING:-DO-NOT-SHARE-THIS...
   ```
3. Сохрани и закрой файл.
> *Ферма также автоматически синхронизируется с Roblox Account Manager (RAM) по файлу `AccountData.json` на Рабочем столе.*

## 🛠️ Справочник и решение возможных проблем (FAQ)

#### 1. Где находится папка `workspace` и `autoexec` в Real?
- По умолчанию они находятся по пути:
  `C:\Users\ТВОЙ_ЮЗЕР\AppData\Local\Real\`
  - `autoexec` — сюда кладем `farm.lua` для автоматического инжекта скрипта.
  - `workspace` — сюда игра сохраняет логи статистики `stats_{userId}.json`.

#### 2. Не запускается несколько окон Roblox (второе окно закрывает первое)
- **Причина:** Стандартное ограничение клиента Roblox (singleton mutex `ROBLOX_singletonMutex`).
- **Решение:** Запусти **Real** от имени администратора перед стартом фермы. Встроенный спуфер Real автоматически снимет этот мьютекс и подменит HWID для мульти-окон.

#### 3. Бот не собирает монеты или пишет "не отвечает"
- Убедись, что в `%localappdata%\Real\autoexec\` лежит файл `farm.lua` с вызовом `loadstring(...)`.
- Проверь, что Real запущен от имени администратора и активен.

#### 4. Как временно поставить ферму на паузу или остановить?
- **Пауза:** В окне Farm Manager нажми большую зелёную кнопку **«⚡ ФЕРМА ВКЛЮЧЕНА»** (она станет серой «⏸️ ФЕРМА НА ПАУЗЕ», запуск новых окон прекратится).
- **Полная остановка:** В консоли нажми комбинацию клавиш `Ctrl + C` и введи `Y`.
